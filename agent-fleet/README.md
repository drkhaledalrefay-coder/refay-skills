# 🤖 Agent fleet — orchestration skills

Three skills for running a fleet of AI coding agents instead of doing every step yourself: a commander that plans, dispatches, time-boxes and judges; a router that probes which local CLIs actually work and sends each job to the right model; and a video conductor that drives whatever fleet is installed through a full motion-graphics or cinematic edit at zero paid-generation cost.

| Skill | Use it when | Key outputs |
| :--- | :--- | :--- |
| [fleet-conductor](fleet-conductor/) | User says "use the fleet", "delegate", or "you supervise", or a multi-step build where you must plan/judge, not execute | Job briefs, time-boxed dispatches, fallback chains, delegated gates (self-tests, schema validation, diffs, screenshots), verification verdicts, finish reports |
| [fleet-orchestrator](fleet-orchestrator/) | User asks to delegate or inspect available agent tools, or a large repetitive task has independent parts that benefit from parallel execution | Fast presence probe; opt-in smoke check; free-agent suggestions; bounded job plan and briefs; verification and summary |
| [motion-forge](motion-forge/) | User says "make a motion graphic/explainer/cinematic video", "use the fleet to edit this video", or drops generated clips to cut | PLAN.md, plates/*.png + INDEX.md, FLOW-PROMPTS.md, TAKES.md/MANIFEST.json, EDL.md, draft_vN.mp4, VO-PROMPT.md, audio/segments/*.wav, final.mp4, final.srt |
