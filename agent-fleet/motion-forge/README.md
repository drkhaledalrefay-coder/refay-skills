# Motion Forge

A phase-by-phase production workflow for coordinating an agent fleet to make a polished explainer or cinematic video.

## At a glance

| | |
| :--- | :--- |
| **Use it for** | Use for a short explainer, motion-graphics or hybrid cinematic video that needs planning, prompts, editing, QA and delivery. |
| **You need** | The video goal, audience, runtime, approved references, available agents and the human who will generate paid media such as video or voice. |
| **It produces** | A locked story/style, generation prompts, reviewed takes, an edit plan or cut, voice/motion guidance, QA notes and delivery checklist as supported. |

## How it works

Discovers the fleet; defines conductor, maker and human roles; runs production phases through briefs and review gates; checks assets and edit decisions.

## What it does not do

The skill does not spend generation credits; the human generates paid media. Editing capabilities depend on connected tools. Not intended for one short animation or a single prompt.

## Install and use

Load the complete `motion-forge` folder using the skills method supported by your AI client. If the client does not support skills, provide [SKILL.md](SKILL.md) as context. Then describe the task and share the inputs listed above.
