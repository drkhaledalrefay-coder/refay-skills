# Lessons from the first production (read before prompts and every revision)

| What went wrong | Rule now |
|---|---|
| Prompts were generic prose; director: "not detailed, no seconds, no reference" | CINEFLOW blocks, per-second timing, references, edit window; paste inline |
| Prompt said lamp left / beads hovering; plate showed lamp right / beads resting | Check each prompt against its plate before sending |
| AI image wrote pseudo-Arabic; 3 attempts failed | Exact text or none; letter-by-letter check; blank-page fallback |
| Baghdad window showed electric city lights / pencil-like pen | Reviewer checks anachronisms; fix by masked grade |
| A take had a second seated person ("drift") | Scan every used span for extra people; take a later clean span |
| Faces/eyes appeared in "effort" shots | Director may allow people; eyes must stay out of frame — list frames checked |
| Grey bars on a phone looked fake | Corner-pin real app screenshots, dim glare 15–20 %, match grain |
| Hero shot (handshake) appeared twice | Story beats appear once; scan whole video for duplicates |
| Last word of the narration cut off | +300 ms tail; whisper the last 10 s |
| Opening lines overlapped each other | Sequential placement, retime picture to voice |
| Two sessions edited/assumed each other's video; voice confusion | One owner per video; confirm voice per video with the director |
| Conductor did work by hand and burned tokens | Conductor writes briefs and reads tails only; even plate checks go to the fleet |
| Codex hit usage limit mid-job; AGY blocked on permissions | Auto-fallback chain; ask once for AGY flag; queue after reset time |
| Director waited without news | Report on every finish; detached watcher opens the file; one-line status when asked |
| Rename collision overwrote v1 backups | Check target before mv/cp; keep versions, never overwrite |
| Brief used a stale script version | Ask the owning session for the current approved file before compiling VO |
