# Example: Roqa kids anime (Google Flow and Seedance)

Reference material from one finished kids anime short, made with the `flow-anime-story` and `seedance-anime-story` skills. Use it to see how a complete shot prompt looks. Do not copy its characters into a new film; write your own locks.

- `worked-shots-flow.md`: the seven Google Flow shot prompts.
- `worked-shots-seedance.md`: the seven Seedance shot prompts.
- `prompt-pack-flow.md`: copy-ready Flow pack, all seven shots.
- `prompt-pack-seedance.md`: copy-ready Seedance pack.
