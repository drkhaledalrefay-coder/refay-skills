# Higgsfield Folder Organizer

Step-by-step guidance for organizing existing images, videos and character sheets inside a Higgsfield.ai project.

## At a glance

| | |
| :--- | :--- |
| **Use it for** | Use when moving, grouping, selecting or downloading assets in an existing project through the browser UI. |
| **You need** | Access to the target Higgsfield project and a clear organization goal. |
| **It produces** | Organized project folders, moved/grouped existing assets or a requested bulk download. |

## How it works

Inspects the visible project; creates or selects folders; moves individual or selected assets; applies project-oriented organization; checks the result.

## What it does not do

Must not trigger media generation. It only works with assets and UI controls actually visible; it cannot claim an operation succeeded without checking.

## Install and use

Load the complete `higgsfield-folder-organizer` folder using the skills method supported by your AI client. If the client does not support skills, provide [SKILL.md](SKILL.md) as context. Then describe the task and share the inputs listed above.
