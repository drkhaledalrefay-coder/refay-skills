# Painterly Action Choreography Engine

Turn an action beat into clear, physically readable, continuity-aware prompts for painterly or cinematic AI video.

## At a glance

| | |
| :--- | :--- |
| **Use it for** | Use for a fight, chase, escape, stunt, impact, multi-shot action beat or image-to-video action prompt. |
| **You need** | The action beat, characters, approved visual references and intended pace/format if known. |
| **It produces** | A structured action prompt or sequence with readable geography, cause and effect, impact and continuity. |

## How it works

Uses references first; locks character details and fight geography; breaks action into clear beats; controls speed and impact; checks physical causality.

## What it does not do

Creates prompts, not footage. It should preserve established character or project facts when references are provided.

## Install and use

Load the complete `painterly-action-choreography-engine` folder using the skills method supported by your AI client. If the client does not support skills, provide [SKILL.md](SKILL.md) as context. Then describe the task and share the inputs listed above.
