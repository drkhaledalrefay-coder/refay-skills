# Painterly Cinematic Character Art

Create or critique character, wardrobe, creature and environment concepts in a specific painterly cinematic visual direction.

## At a glance

| | |
| :--- | :--- |
| **Use it for** | Use in the established painterly-cinematic house style for character designs, outfit concepts, creatures, locations or style critique. |
| **You need** | A character/scene idea and approved style/project references. The skill targets Midjourney v8.1 image prompts. |
| **It produces** | Art direction and image prompts for consistent characters/environments, with optional graphic dust/smoke motion trails. |

## How it works

Sets the style core; shapes design around personality and silhouette; adds wardrobe, depth, lighting and effects; gives corrective direction when reviewing an image.

## What it does not do

This is a specific visual style, not a universal style for every project. It writes prompts and art direction; generation is a separate step.

## Install and use

Load the complete `painterly-cinematic-character-art` folder using the skills method supported by your AI client. If the client does not support skills, provide [SKILL.md](SKILL.md) as context. Then describe the task and share the inputs listed above.
