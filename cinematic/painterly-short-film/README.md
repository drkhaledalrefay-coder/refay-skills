# Painterly Short Film Production

Guide a painterly 2.5D animated short from project setup through character assets, scene prompts, continuity and review in Higgsfield Seedance.

## At a glance

| | |
| :--- | :--- |
| **Use it for** | Use when starting or continuing a short film in the specified painterly/Arcane-inspired direction. |
| **You need** | The story, target runtime, approved visual references, character list and intended production tools. |
| **It produces** | A production structure with style and identity locks, a character asset plan, scene prompts and continuity/review guidance. |

## How it works

Sets up the project; locks visual style; plans character sheets and identity blocks; structures scene prompts and shot names; guides continuity and review.

## What it does not do

This is for the specified painterly short-film pipeline. It guides production and prompts; the user controls media generation and approvals.

## Install and use

Load the complete `painterly-short-film` folder using the skills method supported by your AI client. If the client does not support skills, provide [SKILL.md](SKILL.md) as context. Then describe the task and share the inputs listed above.
