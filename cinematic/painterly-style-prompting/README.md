# Painterly Style Prompting

Turn approved references and a project brief into self-contained, repeatable instructions for painterly images and video.

## At a glance

| | |
| :--- | :--- |
| **Use it for** | Use when creating, revising or reviewing a painterly image, animation or video prompt in any project. |
| **You need** | The project brief, visual references, known style rules, character identity and continuity constraints. |
| **It produces** | A reusable style lock and a complete prompt for the requested output. |

## How it works

Identifies style-authority references; translates painterly qualities into visible choices; builds a reusable lock; makes each prompt independently executable; reviews style and continuity separately.

## What it does not do

Does not impose one house style on every project. Preserve project-specific visual, character, camera and audio rules.

## Install and use

Load the complete `painterly-style-prompting` folder using the skills method supported by your AI client. If the client does not support skills, provide [SKILL.md](SKILL.md) as context. Then describe the task and share the inputs listed above.
