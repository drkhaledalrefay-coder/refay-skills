# Painterly World-Building Engine

Build a coherent visual bible for a painterly cinematic project, covering its look, characters, places, props and keyframes.

## At a glance

| | |
| :--- | :--- |
| **Use it for** | Use to create a new visual world or extend a locked film look consistently across scenes. |
| **You need** | The project premise, source references, story needs and approved identity/style decisions. |
| **It produces** | A visual bible and continuity-ready design guidance for characters, environments, props and keyframes. |

## How it works

Extracts rendering, shape, palette, lighting and detail logic from sources; locks character identity; designs environments and objects; checks choices across shots.

## What it does not do

Does not replace project canon or approved references. It extends what source material supports; media generation and final creative approval remain separate.

Load the complete `painterly-world-building-engine` folder using the skills method supported by your AI client. If the client does not support skills, provide [SKILL.md](SKILL.md) as context. Then describe the task and share the inputs listed above.
