# منتِج فيديو الوايت بورد

خطّط لفيديو شرح بأسلوب السبورة البيضاء، واكتب نصًا واضحًا ومخططًا زمنيًا للمشاهد، ثم جهّز مسار إنتاج عملي يعتمد على الأدوات المتاحة.

## ما الذي تساعدك هذه المهارة على إنجازه؟

- كتابة تعليق صوتي باللغة أو اللهجة المطلوبة.
- إعداد مشاهد محددة التوقيت تحافظ على ترتيب الأفواب والمدة المطلوبة.
- اقتراح نصوص قصيرة على الشاشة ورسوم توضيحية مناسبة لكل مشهد.
- مراجعة الادعاءات والأصول البصرية عند العمل على علامة تجارية أو موضوع منظم.
- تجهيز تعليمات FFmpeg وحزمة نشر ليوتيوب عند الطلب.

## طريقة الاستخدام

أرسل الموضوع والجمهور والمدة ونسبة الأبعاد والمواد المرجعية، وأي تعليق صوتي أو لقطات جاهزة. إذا كانت هذه المعلومات موجودة في المحادثة، تستخدمها المهارة مباشرة ولا تعيد السؤال عنها.

في الموضوعات الطبية أو العلمية أو الإحصائية أو الخاصة بالمنتجات، أرفق المصادر المعتمدة. لا تضف ادعاءً غير موثق، وحافظ على شروطه وسياقه.

## الملفات

- [SKILL.ar.md](SKILL.ar.md) — خطوات العمل ومعايير الجودة بالعربية
- [whiteboard-prompt.ar.md](whiteboard-prompt.ar.md) — برومبت إنتاج جاهز
- [scripts/whiteboard_engine.py](scripts/whiteboard_engine.py) — أداة مجانية لتجميع لوحات المشاهد باستخدام FFmpeg

تجمع الأداة صور اللوحات الجاهزة مع ملف التعليق الصوتي. وهي لا تولّد الرسومات ولا تحرّك يدًا للرسم ولا تستنتج حدود المشاهد؛ جهّز هذه المدخلات في ملف التوقيت.

## الاستخدام السريع

1. جهّز مجلدًا لصور المشاهد بالنسبة المطلوبة.
2. أنشئ ملف JSON للتوقيت يتضمن وقت البداية والنهاية ومسار الصورة لكل مشهد.
3. شغّل الأداة بعد تثبيت FFmpeg وإتاحته في PATH.
4. راجع تزامن الصوت والكتابة واستمرارية الرسومات بعد التصدير.

```powershell
python scripts/whiteboard_engine.py --timeline timeline.json --audio voiceover.mp3 --output final.mp4
```

راجع ترويسة السكريبت لمعرفة بنية ملف التوقيت. FFmpeg أداة منفصلة ومجانية.
