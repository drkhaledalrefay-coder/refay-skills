# منتِج فيديو الوايت بورد

**English:** [Read the English guide](README.md) · [English skill instructions](SKILL.md) · [English production prompt](whiteboard-prompt.md)

تساعدك هذه المهارة على تخطيط فيديو شرح واضح بأسلوب السبورة البيضاء، اعتمادًا على موضوع أو مصادر أو تعليق صوتي جاهز. يحتوي هذا المجلد على تعليمات للمساعد، وبرومبتات قابلة لإعادة الاستخدام، وأداة صغيرة تعتمد على FFmpeg لتجميع **صور لوحات جاهزة** مع التعليق الصوتي في ملف MP4.

![مثال على صورة مصغّرة لفيديو وايت بورد](assets/whiteboard-thumbnail-example.jpg)

*الصورة المصغّرة مثال قدّمه صاحب المهارة. وهي توضح موضوع فيديو الوايت بورد، وليست لقطة أنشأتها أداة التجميع.*

## ماذا تنجز المهارة؟

- تحوّل الموضوع والجمهور إلى فكرة إبداعية ونص تعليق صوتي ومخطط مشاهد بالتوقيت.
- تحافظ على ترتيب المشاهد والطوابع الزمنية والادعاءات ومتطلبات العلامة التجارية التي يحددها المستخدم.
- تصف ما يظهر على السبورة، وتسلسل الرسم، والنص المختصر، والانتقالات، والتعليق الصوتي.
- تراجع الادعاءات التي تحتاج إلى مصادر، وتكشف النواقص بدل اختراع معلومات طبية أو علمية أو إحصائية أو تسويقية.
- تساعد في إعداد ملاحظات الإنتاج، وعند الطلب صورة مصغّرة ونصوص النشر على يوتيوب.
- توفر أداة مجانية تعتمد على FFmpeg لتجميع صور المشاهد والتعليق الصوتي.

## ما الذي لا تنفذه؟

تكتب المهارة الخطط وتعليمات الإنتاج. أما السكريبت فلا يرسم السبورة، ولا يولّد الصور، ولا يحرّك يدًا أو قلمًا، ولا يستنتج توقيت المشاهد، ولا يضيف انتقالات، ولا يتحقق من صحة الادعاءات. وظيفته تجميع صورة جاهزة لكل مشهد مع مسار تعليق صوتي واحد. أنشئ هذه الأصول وراجعها قبل التجميع.

## طريقة الاستخدام

أرسل موجز المشروع إلى مساعد الذكاء الاصطناعي ووجّهه إلى ملف `SKILL.md`، أو انسخ مجلد المهارة إلى مجلد المهارات الذي يستخدمه مساعدك. ويمكنك استخدام ملفات البرومبت مباشرة.

أرفق المعلومات التالية:

1. الموضوع والجمهور وما تريد أن يفهمه المشاهد أو يفعله.
2. المدة الإجمالية ونسبة الأبعاد والدقة ومعدل الإطارات.
3. اللغة ولهجة التعليق الصوتي، وأي تسجيل صوتي موجود.
4. الطوابع الزمنية وترتيب المشاهد إذا كانا محددين مسبقًا.
5. أصول العلامة التجارية والمصادر المعتمدة للادعاءات.
6. المطلوب تسليمه: نص، أو مخطط مشاهد، أو صور، أو فيديو مجمّع، أو حزمة نشر.

مثال على الطلب:

> استخدم هذه المهارة لإعداد فيديو وايت بورد عربي مدته 60 ثانية عن [الموضوع]. التزم بهذه الفترات الزمنية كما هي: [الفترات]. اعتمد المصادر المعتمدة المرفقة لكل الادعاءات. أخرج نصًا صالحًا للإلقاء، وفكرة بصرية واحدة لكل مشهد، وعناوين عربية قصيرة من اليمين إلى اليسار، وقائمة مراجعة للإنتاج. لا تخترع أي ادعاء.

في موضوعات العلامات التجارية أو الموضوعات الطبية والمنظمة، أرفق المواد المعتمدة. ينبغي للمساعد حذف أي ادعاء لا تدعمه هذه المواد وذكره ضمن النقاط التي تحتاج إلى مراجعة.

## تجميع اللوحات الجاهزة باستخدام FFmpeg

### المتطلبات

- Python 3.8 أو أحدث؛ تستخدم الأداة مكتبات Python المدمجة ولا تحتاج إلى تثبيت حزم إضافية.
- تثبيت FFmpeg وإتاحته عبر PATH، أو تمرير مساره إلى الخيار `--ffmpeg`.
- صورة لكل مشهد وملف صوتي واحد للتعليق.

### 1. رتّب ملفات المشروع

تبحث الأداة عن الصور نسبةً إلى مكان ملف التوقيت:

```text
project/
├── timeline.json
├── voiceover.mp3
├── boards/
│   ├── scene_01.png
│   └── scene_02.png
└── final.mp4
```

### 2. اكتب ملف التوقيت

يجب أن يبدأ أول مشهد عند الثانية صفر، وأن تكون الفترات متصلة؛ أي يبدأ كل مشهد عند نهاية المشهد السابق تمامًا.

```json
{
  "width": 1920,
  "height": 1080,
  "fps": 30,
  "scenes": [
    { "start": 0, "end": 8, "image": "boards/scene_01.png" },
    { "start": 8, "end": 15, "image": "boards/scene_02.png" }
  ]
}
```

ينتج المثال فيديو مدته 15 ثانية. عدّل الأبعاد ومعدل الإطارات وأوقات المشاهد ومسارات الصور حسب مشروعك.

### 3. شغّل أداة التجميع

من جذر المستودع:

```powershell
python cinematic/whiteboard-video-producer/scripts/whiteboard_engine.py --timeline path/to/timeline.json --audio path/to/voiceover.mp3 --output path/to/final.mp4
```

أو من داخل مجلد المهارة:

```powershell
python scripts/whiteboard_engine.py --timeline timeline.json --audio voiceover.mp3 --output final.mp4
```

إذا لم يكن FFmpeg متاحًا في PATH، أضف `--ffmpeg "C:\path\to\ffmpeg.exe"`.

تلائم الأداة كل لوحة إطار الفيديو، وتضيف حوافًا بيضاء للمساحة المتبقية، ثم تصل المشاهد وتُصدّر فيديو H.264 مع صوت AAC. ينتهي الملف عند أقصر المسارين: الفيديو المجمع أو التعليق الصوتي، لأن الأداة تستخدم خيار FFmpeg `-shortest`. تأكد أن مدة التعليق تغطي المدة المطلوبة. راجع الملف النهائي للتزامن والإملاء والوضوح وصحة الادعاءات.

## الدقة والمراجعة

- اعتمد مصدر المستخدم للادعاءات الطبية والعلمية والقانونية والإحصائية والخاصة بالمنتجات.
- حافظ على القيود والسياق والفئة المدروسة والتواريخ. لا تحوّل نتيجة محدودة إلى ضمان.
- اكتب العربية من اليمين إلى اليسار وراجع ظهورها في الملف النهائي؛ فقد تخطئ مولدات الصور في رسم النصوص الدقيقة.
- لا تقل إن أصلًا قد تم توليده أو تصديره أو اختباره أو رفعه أو نشره ما لم يحدث ذلك فعلًا.
