# Whiteboard Video Producer

**العربية:** [اقرأ الدليل العربي](README.ar.md) · [تعليمات المهارة بالعربية](SKILL.ar.md) · [برومبت الإنتاج بالعربية](whiteboard-prompt.ar.md)

Plan a clear, evidence-led whiteboard explainer from a topic, source pack, or existing narration. This folder contains the agent instructions, reusable briefs, and a small FFmpeg helper for assembling **prepared still boards** into a narrated MP4.

![Whiteboard video thumbnail example](assets/whiteboard-thumbnail-example.png)

## What this skill does

- Turns a topic and audience into a concise creative direction, narration, and a timed storyboard.
- Preserves supplied scene order, exact time ranges, claims, and brand requirements.
- Specifies what appears on the board, when it is drawn, short on-screen copy, transitions, and voice-over.
- Checks source-sensitive claims and identifies gaps instead of inventing product, medical, scientific, or statistical facts.
- Helps prepare production notes and, when requested, a thumbnail and YouTube publishing copy.
- Offers a free FFmpeg-based helper to join scene-board images with narration.

## What it does not do

The skill writes plans and production instructions. The helper script does **not** draw the board, generate images, animate a hand or marker, create scene timings, add transitions, or verify claims. It assembles one prepared image per scene and one narration track. Create and review those assets first.

## Use the skill

Give your AI assistant the project brief, then point it to `SKILL.md` (or install this folder in the assistant's skills directory). You can also use the prompt files directly.

Include:

1. Topic, audience, and what viewers should understand or do.
2. Total duration, aspect ratio, resolution, and frame rate.
3. Language and voice-over dialect, plus any recorded narration.
4. Required timestamps and scene order, if already decided.
5. Brand assets and authoritative source files for claims.
6. Desired deliverables: script, storyboard, images, assembled video, or publishing package.

Example request:

> Use this skill to create a 60-second Arabic whiteboard explainer for [topic]. Keep these scene times exactly: [ranges]. Use the attached approved sources for all claims. Return a read-aloud voice-over, one visual idea per scene, concise RTL labels, and a production checklist. Do not invent claims.

For a branded or regulated subject, provide the approved materials. The assistant should omit unsupported claims and list them for review.

## Assemble prepared boards with FFmpeg

### Requirements

- Python 3.8 or newer (standard library only; no Python packages required).
- FFmpeg installed and available on your PATH, or provide its executable with `--ffmpeg`.
- One image per scene and one narration audio file.

### 1. Arrange your project

The helper resolves image paths relative to the timeline JSON file:

```text
project/
├── timeline.json
├── voiceover.mp3
├── boards/
│   ├── scene_01.png
│   └── scene_02.png
└── final.mp4
```

### 2. Write the timeline

Scene ranges must begin at 0, be contiguous, and have each scene start exactly when the previous one ends.

```json
{
  "width": 1920,
  "height": 1080,
  "fps": 30,
  "scenes": [
    { "start": 0, "end": 8, "image": "boards/scene_01.png" },
    { "start": 8, "end": 15, "image": "boards/scene_02.png" }
  ]
}
```

This example produces 15 seconds of video. Change the dimensions, frame rate, scene ranges, and image paths to fit your project.

### 3. Run the assembler

Run from the repository root:

```powershell
python cinematic/whiteboard-video-producer/scripts/whiteboard_engine.py --timeline path/to/timeline.json --audio path/to/voiceover.mp3 --output path/to/final.mp4
```

If you are already inside this skill folder:

```powershell
python scripts/whiteboard_engine.py --timeline timeline.json --audio voiceover.mp3 --output final.mp4
```

If FFmpeg is not on PATH, append `--ffmpeg "C:\\path\\to\\ffmpeg.exe"`.

The helper scales each board to fit the requested frame, pads unused space with white, concatenates scenes, and encodes H.264 video with AAC audio. Output ends at the shorter of the assembled video and narration because FFmpeg's `-shortest` option is used; make sure the narration duration covers the intended runtime. Review the exported file for sync, spelling, legibility, and claim accuracy.

## Accuracy and review

- Use the user's source of truth for product, medical, scientific, legal, and statistical claims.
- Preserve qualifications, study population, dates, and context. Do not turn a limited observation into a guarantee.
- Keep Arabic right-to-left and proofread it in the final rendered medium; model-generated images often mishandle exact text.
- Do not say an asset was generated, rendered, tested, uploaded, or published unless that actually happened.
