# 📣 Marketing — campaign and profile skills

Five skills for marketing work that has to fit a real brand: plan digital campaigns in any market, build a training course for a product range, produce a full AI-generated UGC video campaign, rewrite a prompt to be token-efficient, and turn a GitHub account into a professional profile page.

| Skill | Use it when | Key outputs |
| :--- | :--- | :--- |
| [brand-campaign-planner](brand-campaign-planner/) | Plan digital campaigns in any market: platform strategy, content calendars, creator/UGC briefs, PDP copy, claims and compliance review. | Brand dossier, market adaptation sheet, channel plan, pillars and calendar, captions/scripts, creator briefs, PDP copy, cleared assets, KPI framework. |
| [github-profile-builder](github-profile-builder/) | Make a GitHub profile professional: profile README, sidebar bio, pinned repos, for developers or LinkedIn-style non-developers. | GitHub profile README, 3 sidebar bio options, badge/stats verification, preview.html, pinned-repo and per-repo README guidance, setup guide. |
| [product-range-course-builder](product-range-course-builder/) | Build a training course for any brand's product range from brand guide and source docs, or edit, restyle or QA an existing range course. | Verified Brief, asset inventory and rename list, one Builder prompt, lesson content with complex/comparison blocks, QA gate report, brand-guide.md. |
| [prompt-optimum](prompt-optimum/) | Rewrite a draft prompt or chat message into a token-efficient version before sending to any LLM/tool, when asked to optimize or tighten it. | One optimized prompt in a copy-paste code block, optional single clarifying question, updated references/patterns.md shorthand log. |
| [ugc-campaign-studio](ugc-campaign-studio/) | Plan an AI-generated UGC video campaign for any brand: personas, native-dialect scripts, still and Flow/Veo clip prompts, playbook deck. | brief.json, analysis.md, products.json, content.json, persona_prompts.md, holding_prompts.md, clip prompts with SCALE LOCK, deck.pptx, deck.pdf, QA report. |
