## No Claude Code? Use the prompt
Open `UNIVERSAL_PROMPT.md`, fill in the fields, and paste it into Claude, ChatGPT or any AI. Same design, no install needed.

## Install
- **Claude Code:** unzip into `~/.claude/skills/` so you have `~/.claude/skills/github-profile-builder/SKILL.md`.
- **claude.ai:** Settings → Capabilities → Skills → upload the zip.

## Use
Say: *"Make my GitHub profile professional"* — Claude will ask a few questions, write your README, check every badge loads, and only publish after you say yes.

## Example
Replace this line with a link to a profile you built with this skill — e.g. `https://github.com/<username>` — or delete it if you have none to show.
