# Product Range Course Builder

Turn official brand and product sources into a structured training course for a sales or retail team.

## At a glance

| | |
| :--- | :--- |
| **Use it for** | Use for a product-range course, sales/pharmacy/beauty-adviser training, certification or course QA. |
| **You need** | The brand guide, official product documents/assets, learner group, market/language needs and format constraints. |
| **It produces** | A verified product brief and structured course build brief for the implementation workflow, grounded in provided sources. |

## How it works

Reads brand and product materials; inventories assets; organizes lessons and requirements; applies range content rules; prepares a verified handoff.

## What it does not do

Product claims must come from official sources. The workflow does not infer missing product facts.

## Install and use

Load the complete `product-range-course-builder` folder using the skills method supported by your AI client. If the client does not support skills, provide [SKILL.md](SKILL.md) as context. Then describe the task and share the inputs listed above.
