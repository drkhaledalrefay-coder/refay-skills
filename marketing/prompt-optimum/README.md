# Prompt Optimum

Rewrite a message or AI prompt to use fewer words while preserving instructions needed for a precise result.

## At a glance

| | |
| :--- | :--- |
| **Use it for** | Use when tightening a draft before sending it to an AI or another tool. |
| **You need** | The draft text and, if unclear, the intended tool and outcome. |
| **It produces** | A shorter, clearer prompt that retains context, constraints, output format and tone. |

## How it works

Identifies the task and must-keep details; removes repetition; resolves avoidable ambiguity; returns a ready-to-send rewrite; can learn recurring phrasing patterns through a local pattern log.

## What it does not do

Efficiency does not mean deleting important constraints. It rewrites the request; it does not do the task inside it.

## Install and use

Load the complete `prompt-optimum` folder using the skills method supported by your AI client. If the client does not support skills, provide [SKILL.md](SKILL.md) as context. Then describe the task and share the inputs listed above.
