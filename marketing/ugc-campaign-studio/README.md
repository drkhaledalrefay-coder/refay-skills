# UGC Campaign Studio

Plan a UGC-style video campaign with evidence-based product messaging, relatable personas and production-ready creative materials.

## At a glance

| | |
| :--- | :--- |
| **Use it for** | Use for a multi-video social campaign, testimonial-style concepts or an AI-generated UGC playbook. |
| **You need** | Brand/product sources, market/language, audience, campaign goal, channel, approved claims and required disclosures. |
| **It produces** | Campaign concepts/personas, scripts, still/video prompts, product-scale references and a playbook deck when requested by the workflow. |

## How it works

Intakes needs; checks brand/product evidence; creates personas and platform-native scripts; prepares prompts; assembles the playbook and checks prompt structure.

## What it does not do

UGC describes a creative format; it does not create real customer endorsements. Claims need sources, and synthetic-content/disclosure rules must be followed.

## Install and use

Load the complete `ugc-campaign-studio` folder using the skills method supported by your AI client. If the client does not support skills, provide [SKILL.md](SKILL.md) as context. Then describe the task and share the inputs listed above.

Supporting guidance is in `references/`; the content schema is in `templates/`; the prompt checker is in `scripts/`.
