# 🛠️ Vibe coding — build and audit skills

Four skills for people who build software with AI: architect a new project to professional standards or refactor a messy one, ship a scroll-driven cinematic hero, and audit a live site or AI-generated codebase for production-readiness before you deploy, hand off or onboard it.

| Skill | Use it when | Key outputs |
| :--- | :--- | :--- |
| [cinematic-hero](cinematic-hero/) | Building a scroll-driven cinematic hero: two-video crossfade or canvas frame-sequence scrubbing ('cinematic hero', 'scroll video hero'). | Sticky stage/flow, two-video crossfade JS, mobile and landscape CSS, canvas frame-sequence engine, FFmpeg re-encode and poster commands, anti-slop checklist. |
| [vibe-architect](vibe-architect/) | Planning a new app (greenfield blueprint) or professionalizing a messy AI-built codebase (brownfield), e.g. 'refactor old project'. | Greenfield build blueprint, module breakdown, data-model spec, AGENTS.md verification rules; brownfield ARCHITECTURE.md, modularization plan, Git/test hygiene. |
| [vibe-code-audit](vibe-code-audit/) | Auditing a live site or codebase for production-readiness, security or performance before deployment, client handoff or onboarding. | Weighted six-pillar scorecard, maturity tier verdict, band-aid vs root-cause analysis, prioritized remediation roadmap, structured audit report. |
| [vibe-coding-project-auditor](vibe-coding-project-auditor/) | Auditing a vibe-coded/AI-generated app for production readiness before deployment; runs a 7-dimension scan and scored HTML report. | docs/reports/vibe-audit-{date}.md report, 7-dimension scores 1–10, composite verdict, P0/P1/P2 remediation plan, scored HTML Artifact with score gauge/bars. |
