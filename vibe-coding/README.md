# 🛠️ Vibe coding — build and audit skills

Four skills for people who build software with AI: architect a project, build a scroll-driven cinematic hero, review live infrastructure and deployment operations, or inspect code in an AI-generated application repository. The two audit skills have separate scopes.

| Skill | Use it when | Key outputs |
| :--- | :--- | :--- |
| [cinematic-hero](cinematic-hero/) | Building a scroll-driven cinematic hero: two-video crossfade or canvas frame-sequence scrubbing ('cinematic hero', 'scroll video hero'). | Sticky stage/flow, two-video crossfade JS, mobile and landscape CSS, canvas frame-sequence engine, FFmpeg re-encode and poster commands, anti-slop checklist. |
| [vibe-architect](vibe-architect/) | Planning a new app (greenfield blueprint) or professionalizing a messy AI-built codebase (brownfield), e.g. 'refactor old project'. | Greenfield build blueprint, module breakdown, data-model spec, AGENTS.md verification rules; brownfield ARCHITECTURE.md, modularization plan, Git/test hygiene. |
| [vibe-code-audit](vibe-code-audit/) | Reviewing live infrastructure, deployment, security and operational risk for a web platform when the relevant access is available. | Evidence-led findings, scope and access limits, heuristic six-pillar triage score, prioritized remediation roadmap. |
| [vibe-coding-project-auditor](vibe-coding-project-auditor/) | Reviewing tracked code and configuration in an AI-generated app repository; it does not verify live hosting or real-world capacity. | Evidence-linked Markdown report, optional heuristic seven-dimension scores, confidence and limitations, prioritized remediation plan; optional visual summary when supported. |
