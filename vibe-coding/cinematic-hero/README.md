# Cinematic Hero

Build a website hero that uses scroll to reveal a cinematic video sequence or scrub through a frame sequence.

## At a glance

| | |
| :--- | :--- |
| **Use it for** | Use for a full-viewport hero with a scroll-driven video crossfade or canvas frame scrubbing. |
| **You need** | The website project, hero content/assets, target devices and preferred interaction pattern. |
| **It produces** | An implementation plan or code for the selected hero, with mobile-aware media guidance and known-bug checks. |

## How it works

Chooses between two-video crossfade and canvas frames; lays out architecture and interactions; handles mobile/landscape cases; checks playback/overlay issues.

## What it does not do

Limited to the hero section and documented patterns. Compatibility and performance depend on supplied media and the target site; it does not create video assets.
