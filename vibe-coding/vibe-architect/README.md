# Vibe Architect

Plan a sound software structure for a new project or professionalize an existing codebase with clear modules and build stages.

## At a glance

| | |
| :--- | :--- |
| **Use it for** | Use for a greenfield build plan, architectural refactor or codebase organization, especially for AI-assisted building. |
| **You need** | The project goal, users/workflows and constraints; repository access for an existing codebase. |
| **It produces** | A modular architecture, data model, agent rules and phased build plan, or a scoped improvement plan. |

## How it works

Extracts requirements and domain boundaries; defines modules/data; sets verification and repository rules; sequences work into phases; inspects existing code before proposing changes.

## What it does not do

A plan does not mean implementation is complete. Architecture is grounded in the project evidence and stated constraints.

## Install and use

Load the complete `vibe-architect` folder using the skills method supported by your AI client. If the client does not support skills, provide [SKILL.md](SKILL.md) as context. Then describe the task and share the inputs listed above.
