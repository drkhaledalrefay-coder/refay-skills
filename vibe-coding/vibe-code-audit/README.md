# Vibe Code Audit

Run a rigorous, evidence-based engineering audit of a web app or codebase, with a scored report and prioritized next steps.

## At a glance

| | |
| :--- | :--- |
| **Use it for** | Use before deployment, production handoff, client delivery, or to assess architecture, security, performance or readiness. |
| **You need** | The codebase/app scope, relevant source/deployment context and permission to inspect requested environments. |
| **It produces** | A maturity assessment, scores across audit pillars, evidence, executive verdict and prioritized fixes. |

## How it works

Scopes projects; assigns audit lanes when suitable tools exist; inspects six engineering pillars; aggregates evidence; scores maturity; writes a technical report.

## What it does not do

Findings depend on accessible evidence. A score is not a guarantee of security or production readiness; unknowns should be reported.

## Install and use

Load the complete `vibe-code-audit` folder using the skills method supported by your AI client. If the client does not support skills, provide [SKILL.md](SKILL.md) as context. Then describe the task and share the inputs listed above.
