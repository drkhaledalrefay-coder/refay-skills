# Vibe Coding Project Auditor

Inspect an AI-generated application across seven dimensions and produce a scored, evidence-backed HTML audit report.

## At a glance

| | |
| :--- | :--- |
| **Use it for** | Use for a structured production-readiness and architecture inspection of a vibe-coded application. |
| **You need** | Access to project files and relevant environment information, plus a place to save/display the report artifact. |
| **It produces** | A seven-dimension inspection with findings and score/classification in an HTML report. |

## How it works

Orients without editing; scans infrastructure, APIs, caching, data/concurrency, authentication, architecture and stack fit; records evidence; scores and classifies.

## What it does not do

An audit describes inspected evidence; it is not a guarantee or a repair. Distinguish unavailable evidence from confirmed defects.
